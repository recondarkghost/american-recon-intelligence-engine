AMERICAN RECON INTELLIGENCE ENGINE

Windows requirements:
- Python 3.10 or newer
- Internet connection for live data feeds

Run:
Double-click START_AMERICAN_RECON.bat
or open Command Prompt in this folder and enter: py server.py

The browser opens at http://127.0.0.1:8765
Keep the Command Prompt window open while using the engine.
Press Ctrl+C to stop it.

Data is refreshed every 15 minutes and stored locally in:
american_recon_intelligence.db

Important:
The engine starts with unproven probabilities. It creates a dated forecast ledger
so calibration and error can be measured as forecasts mature. It does not guarantee
80% accuracy and cannot predict exact dates for wars, earthquakes or disasters.
